# Q: Miraのキーボード解除、日別タイムライン、候補日選択、余白カテゴリ統合を実装するにはどこを変更するか

## Answer

HomeViewとMonthCalendarGridからDayTimelineViewへ遷移し、MiraQuickInputBarのFocusStateを親へ公開。MiraStore+ConversationのcandidateDatesによるhard filterを除去し、広い期間は全日を保持。MarginKindのlegacy aliasをrestへcanonicalizeし起動時移行を追加。
