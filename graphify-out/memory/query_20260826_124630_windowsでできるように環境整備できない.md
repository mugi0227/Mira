# Q: windowsでできるように環境整備できない？

## Answer

Expanded from original query via graph vocabulary: [swift, app, apple, xcode, foundation, models, data, calendar, notification, notifications]. Mira targets iOS and depends on SwiftUI plus Apple-only frameworks such as SwiftData, UIKit, UserNotifications, and Foundation Models. A Windows Swift toolchain can build portable Swift code but cannot build or run this iOS application. The practical Windows route is to build an iOS Simulator .app on GitHub Actions and stream it in a browser service such as Appetize, or use a remote Mac with Xcode.
