# Mira 会話入口・日程調整 要求仕様 Part 2

**文書種別:** Canonical Requirements Extension  
**由来:** Grill-Me Q73以降  
**位置づけ:** `requirements-conversational-assistant.md` の続編。後で本体へ統合してよい。

## FR-C080 仮条件生成後は即、日程調整モードへ遷移する

Miraが自然言語入力から所要時間・時間帯等を合理的に仮定できた場合、`この条件で探す？` のような確認画面を挟まず、同じ月間カレンダーを日程調整モードへ切り替える。

## FR-C081 おすすめ候補を遷移直後から表示する

日程調整モードへ入った時点で、Miraが自動選定した2〜5件の候補を最初から表示し、第一候補を明確に強調する。

## FR-C082 仮条件は常に修正可能な形で残す

AIまたはフォールバックロジックが推定した所要時間・時間帯は、画面上部に編集可能なチップとして表示する。

例:

- `1〜2時間 ×`
- `夜 ×`

変更時は候補を即再計算する。

## UX原則

**入力 → 即、候補付きカレンダー。確認のためだけの中間画面は増やさない。**
