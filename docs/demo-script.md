# Demo Script

## Recording setup

- iPhone 17 Pro Simulator
- portrait
- demo clock: 2026-09-01 10:00 JST
- Pixel Cat skin
- begin from reset state

## 90-second narrative

1. **Onboarding** — select rest, reading, personal project, important people, and two free evenings per week.
2. **Auto placement** — show large rest blocks appearing around existing plans.
3. **Protect margin** — add a social event on a protected rest day; choose a suggested relocation date.
4. **Pending invitation** — open the existing pending dinner invitation and inspect projected load.
5. **Adjustment** — convert to adjustment, show selected candidates and an overlapping hold.
6. **Share** — copy or share the generated LINE-ready sentence.
7. **Confirm** — choose one candidate; show other holds released and cat success state.
8. **Load correction** — open an all-day salon event, view reason, correct to normal, optionally remember.
9. **Future month** — navigate to November; provisional plan is copied and a crowded weekend warning appears.
10. **Import** — show Yahoo! Calendar source, analysis animation, birthdays/recurring items, duplicate resolution.

## Message to land

> Mira is not a calendar that finds more room. It is a calendar that protects the life you wanted before the invitations arrived.
