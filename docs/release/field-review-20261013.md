# 実機フィードバックの修正（0.2.1）

## 変更

- 余白量の「少なめ」は、各目標を月1回にする。「ふつう」「多め」と丸めで同じ数にならないようにする。
- iPhoneカレンダーへの接続時に日常の日時へ切り替える。既存の接続設定も初回起動時に移行する。チャットは質問した期間を更新してから予定・空き・余白を調べる。EventKitの変更通知とアプリ復帰時にも更新する。
- 「今週」は月曜から翌月曜までの範囲で調べる。期間は開始を含み、終了を含まない。日をまたぐ予定は翌日や次の月にも表示する。
- 保存した組み直し案は、現在表示している月のものだけを選ぶ。他の月の再計算で表示中の案を差し替えない。
- 猫スキンのタブを画面本体と縦に配置し、設定リストがタブの下へ潜らないようにする。
- 仕事・学校の時間を設定画面から編集できるようにする。オンボーディングと同じ編集画面に「平日まとめて変更」を追加し、月〜金の時刻を一括適用する。
- 友達向け表示と共有画像は、朝（8–12時）・昼（12–18時）・夜（18–24時）の空きを示す。予定名は隠す。時間帯内に予定・余白・仕事時間があれば「予定」と表示する。誕生日は空きを塞がない。
- マイ余白の各目標で、今後置く枠の所要時間を30分単位で設定できる。名前・回数・所要時間を持つオリジナル目標を複数追加できる。自動配置・組み直し・手動追加・達成数はそれぞれの目標を区別する。
- 配置済みの余白は詳細から1枠の所要時間を変更できる。重複があれば確認画面へ進み、取り消しにも対応する。目標の既定時間と個別の枠は別々に編集する。
